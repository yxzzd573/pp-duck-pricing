## PP 鸭能干什么，干不了什么

官网把它的定位写得很直白：整合几种开源压缩算法，自动按图片特征挑参数。你不用懂 PNG 和 JPEG 该用哪种量化，拖进去就行。可以设保存路径、输出尺寸、输出格式，v3 支持 WebP，这对做前端的人有用，WebP 比同画质的 JPEG 小一截。

官网列的适用人群有五类：开发工程师、网站设计师、网店店主、摄影师、内容编辑。这五类人有个共同点，手上都有一批图要处理，又不想为这件事去学命令行。

但它的能力到此为止，具体差在这几处：

**默认是原地压缩。** 拖进去就直接改文件，虽然能设保存路径，但第一次用的人容易忽略这一步，把原图覆盖掉。养成先设输出目录的习惯，或者先拿一批不重要的图试手。

**没有自动化。** 它不能盯着一个文件夹自动压新进来的图，不能在你复制图片到剪贴板时自动压缩替换，也不支持 URL Scheme 接进工作流。这三项恰好是 Zipic 的卖点。如果你想要的是「我把图存进去就再也不用管」，PP 鸭满足不了。

**平台细节没说清。** Windows 版和 Mac 版的功能是不是完全一致，页面没有逐项对比。

**搜英文资料会被误导。** 拿 PPDuck 去搜，能翻到把 PPDuck3 描述成 PDF 编辑器、带 AI OCR 和云端协作的页面，功能表列得像模像样，全是编的。这软件跟 PDF 一个字都不沾。看到这类站点直接关掉。

## 谁该买，谁不用买

只做一件事的人买 PP 鸭：手上有大量图片要批量压小，用 Windows 或者 Mac，不想折腾脚本。103 元，一次付清，不用每个月想着退订。

- 你的图片主要是要精细修图的素材。压缩工具的自动参数是给「发出去用」的图准备的，不是给后期流程准备的。
